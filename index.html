Excel for the web

Link a workbook on OneDrive or SharePoint. Edits here are written back to it, and it is read again when you open the page.

How to set this up (one time)
  1. In the Microsoft Entra admin center, open App registrations → New registration.
  2. Add a redirect URI of type Single-page application:
  3. Under API permissions, add Microsoft Graph, delegated, Files.ReadWrite.All.
  4. Copy the Application (client) ID into the box above.
  5. In Excel for the web, choose Share → Copy link (anyone in your org who has the link can edit) and paste it above.

If your organisation blocks app registration or needs admin approval, ask your IT team to do steps 1 to 3 for you.
